What actually changed in v0.18.0

  • Design tokens. A complete Tailwind v4 @theme token system in index.css (+117 / −34): semantic colors (action, success, danger, warning, purple, amber), bg layers (base/surface/elevated/sunken/glass), text scale (primary/secondary/tertiary/muted), and shared radius/shadow scales. Light theme added.
  • New components/ui/ primitives. 8 new files: GlassPanel, Button, Badge, Banner, Modal, StatusDot, Tabs, Input. Virtually every existing component (Settings, Diff, FileBrowser, Todo, Prompts, SessionCard, etc.) was rewritten to consume these.
  • Apple-style glass aesthetic. Frosted backdrop-filter: blur(20px) surfaces over a near-black #0a0a0f base, Inter font, generous radii (10/14/20px), and soft shadows. Status dots glow + pulse.
  • Dashboard rewrite (95 +/−101 lines). New banner stack (LB Shared install, tmux mouse setup, first-run repo dir, upgrade nag with rotating Office Space quotes), cloud-plan meter in the header, Active/Inactive section split, scratch session button (Zap).
  • Login rewrite. Replaced with a centered GlassPanel + Input + Button composition.
  • TerminalHeader rewrite (+77/−49). New glass row, session-navigator dots, brain/clear/reset/font-size quick actions, click/Shift+click to cycle sessions.
  • PWA polish. New PWAUpdatePrompt component + 27 lines added to useTerminalSocket + 34 lines to main.tsx (service-worker registration). Safe-area insets honored in body padding.
