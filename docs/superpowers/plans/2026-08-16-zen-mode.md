# Zen Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alt+Z toggles a full-bleed terminal on the desktop session page, without touching the session's saved tab-visibility settings.

**Architecture:** Zen is frontend view state held by a new `useZenMode()` hook and persisted to `localStorage` under `lumbergh:zenMode`, matching how `ResizablePanes` persists layout. `SessionDetail` gains a third desktop render branch that swaps `ResizablePanes` for a full-height terminal wrapped in a new presentational `ZenTerminal`. The Alt+Z chord is declined by xterm so it reaches the window listener instead of tmux.

**Tech Stack:** React 19 + TypeScript, Vite, Tailwind, xterm.js, vitest (unit), Playwright + pytest-bdd (UI E2E).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-16-zen-mode-design.md`. Read it before starting.
- Desktop only. `useIsDesktop()` is `(min-width: 768px)`. Mobile behavior must not change.
- Saved tab visibility must never be written by zen. This is the whole point of the feature — the existing **Terminal Only** checkbox already fails here.
- Esc must never exit zen. It is load-bearing inside Claude Code and vim. The same Alt+Z chord toggles both directions.
- `localStorage` key is exactly `lumbergh:zenMode`, storing `'true'` / `'false'`.
- Run `./lint.sh` from the repo root before any commit. It auto-fixes and exits non-zero on unfixable errors.
- The backend (`:8420`) and vite (`:5420`) already run in the bootstrap tmux window. Do not start or kill them.

- [ ] **Step 3: Create the module**

Create `frontend/src/utils/terminalChords.ts`. The doc comment is moved verbatim from `Terminal.tsx:57-60` and extended for the new chord:

```ts
/** Chords that drive the app rather than reaching the shell: Ctrl+[ / Ctrl+],
 * Alt+Left / Alt+Right, and Alt+Z. xterm must decline them so they bubble to the
 * window listeners in SessionDetail, useSessionSwitchKeys and useZenMode — and so
 * they never reach tmux as escape sequences. */
export function isSessionCycleChord(event: KeyboardEvent): boolean {
  if (event.ctrlKey && (event.key === '[' || event.key === ']')) return true
  if (event.metaKey) return false
  if (event.altKey && (event.key === 'ArrowLeft' || event.key === 'ArrowRight')) return true
  return event.altKey && !event.ctrlKey && event.key.toLowerCase() === 'z'
}
```

`key.toLowerCase()` matters: some platforms report `Z` when a modifier is held.

from playwright.sync_api import Page, expect
from pytest_bdd import given, parsers, scenarios, then, when

scenarios("features/session_zen.feature")

SESSION = "e2e-ui-session"


@when(parsers.parse('I press "{chord}"'))

    page.keyboard.press(chord)


@then("I should see the git tab button")
def see_git_tab_button(page: Page):
    expect(page.locator('[data-testid="tab-git"]')).to_be_visible(timeout=10000)


@then("I should not see the git tab button")
def no_git_tab_button(page: Page):
    expect(page.locator('[data-testid="tab-git"]')).to_have_count(0, timeout=10000)


def _saved_tab_visibility(base_url: str):
    with httpx.Client(base_url=base_url, timeout=10.0) as client:
        r = client.get("/api/sessions")
        r.raise_for_status()
        for session in r.json()["sessions"]:
            if session.get("name") == SESSION:

    raise AssertionError(f"session {SESSION} not found")


@given("I record the session's saved tab visibility", target_fixture="saved_tab_visibility")
def record_tab_visibility(base_url: str):
    return _saved_tab_visibility(base_url)


@then("the session's saved tab visibility is unchanged")

    assert _saved_tab_visibility(base_url) == saved_tab_visibility

- [ ] **Step 1: Write the hook**

Create `frontend/src/hooks/useZenMode.ts`. It is modeled on `useSessionSwitchKeys.ts` — desktop-only window listener, `preventDefault()` so the chord does not leak:

```ts
import { useCallback, useEffect, useState } from 'react'
import { useIsDesktop } from './useMediaQuery'

const STORAGE_KEY = 'lumbergh:zenMode'

/** Zen mode: the terminal fills the desktop viewport, with the side panel and page
 * banners not rendered. Alt+Z toggles it in both directions — Esc is deliberately
 * not an exit key, because the terminal needs it.
 *
 * State lives in localStorage rather than server settings: it is a per-browser view
 * preference, like the ResizablePanes widths, and toggling must be instant. */
export function useZenMode() {
  const isDesktop = useIsDesktop()
  const [isZen, setIsZen] = useState(() => localStorage.getItem(STORAGE_KEY) === 'true')

  const setAndStore = useCallback((next: boolean) => {
    setIsZen(next)
    localStorage.setItem(STORAGE_KEY, String(next))
  }, [])

  const toggleZen = useCallback(() => setAndStore(!isZen), [isZen, setAndStore])
  const exitZen = useCallback(() => setAndStore(false), [setAndStore])

  useEffect(() => {
    if (!isDesktop) return

    const onKeyDown = (e: KeyboardEvent) => {
      if (!e.altKey || e.ctrlKey || e.metaKey) return
      if (e.key.toLowerCase() !== 'z') return
      e.preventDefault()
      setAndStore(!isZen)
    }

    window.addEventListener('keydown', onKeyDown)
    return () => window.removeEventListener('keydown', onKeyDown)
  }, [isDesktop, isZen, setAndStore])

  return { isZen: isDesktop && isZen, toggleZen, exitZen }
}
```

`isZen` is gated on `isDesktop` in the return so a narrow viewport can never render the zen layout, while the stored preference survives for when the window widens again.

- [ ] **Step 2: Write the wrapper**

Create `frontend/src/components/ZenTerminal.tsx`. It owns the fading exit affordance and nothing else — it does not know what zen means or how it is stored:

```tsx
import { useCallback, useEffect, useRef, useState } from 'react'

const HIDE_AFTER_MS = 2000

interface ZenTerminalProps {
  children: React.ReactNode
  onExit: () => void
}

export default function ZenTerminal({ children, onExit }: ZenTerminalProps) {
  const [showExit, setShowExit] = useState(false)
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null)

  const revealExit = useCallback(() => {
    setShowExit(true)
    if (timerRef.current) clearTimeout(timerRef.current)
    timerRef.current = setTimeout(() => setShowExit(false), HIDE_AFTER_MS)
  }, [])

  useEffect(() => () => { if (timerRef.current) clearTimeout(timerRef.current) }, [])

  return (
    <div className="h-full relative" onMouseMove={revealExit}>
      {children}
      <button
        onClick={onExit}
        data-testid="zen-exit"
        className={`absolute top-2 right-2 z-30 px-2 py-1 rounded bg-bg-surface/80 border border-border-default text-text-tertiary hover:text-text-primary text-xs transition-opacity backdrop-blur-sm ${
          showExit ? 'opacity-100' : 'opacity-0 pointer-events-none'
        }`}
        title="Exit zen mode (Alt+Z)"
      >
        Exit zen
      </button>
    </div>
  )
}
```

The classes mirror the existing "Tabs" button at `SessionDetail.tsx:736-742` so the two affordances read as siblings.
